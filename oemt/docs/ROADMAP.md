# OEmt.club Roadmap

Edit freely. Status: ✅ done · 🔨 in progress · ⬜ planned · 💡 idea

## Phase 1: Foundation ✅
- ✅ Full fork of Millennium, renamed to OEmt.club (`Steam\oemt\`, `oemt.*` files)
- ✅ OEmt.club page inside Steam with tabs: Home, Library, Sessions, Integrations, Performance, Network, Settings, Diagnostics
- ✅ Opens automatically when Steam starts; "OEmt.club Home" in the Steam menu
- ✅ Game sessions recorded from Steam's start/stop events
- ✅ OEmt.club theme (SpaceTheme layout, OEmt branding, editable colors, Lucida Console)
- ✅ Own-IP log (auto + per session), opt-in
- ✅ Settings import/export, diagnostics, self-test, redacted exports

## Phase 2: Gaming environment
- 🔨 Account Center: switch Steam accounts through TcNo, labels, switch-then-launch
- ⬜ Profiles & workspaces (competitive / casual / streaming setups)
- ⬜ Notes per game
- ⬜ Discord Rich Presence (needs a Discord application ID)
- ⬜ Spotify now playing (needs a Spotify developer client ID; controls need Premium)
- ⬜ SoundCloud (check if their API allows it first)

## Phase 3: Advanced
- ⬜ Automation rules (game starts → switch workspace, etc.)
- ⬜ Insights.gg (open app, clip links)
- ⬜ Overlay options that don't touch games (no anti-cheat risk)
- ⬜ Extension API for other plugins
- ⬜ Optional AI assistant (off by default)
- ⬜ Optional PIN lock for the OEmt.club UI

## Phase 4: Media
- ⬜ Media Hub (YouTube, Twitch, etc. in an isolated browser window)
- ⬜ OEmt Browser
